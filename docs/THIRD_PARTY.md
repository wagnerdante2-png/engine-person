# Third-party model attribution

## FLAME2023_Open

Engine Person can use a derived runtime mesh from **FLAME2023_Open**, provided by the Max Planck Institute for Intelligent Systems / FLAME project.

- Project: FLAME - Learning a model of facial shape and expression from 4D scans
- Authors: T. Li, T. Bolkart, M. J. Black, H. Li, J. Romero
- Original publication: ACM Transactions on Graphics (Proc. SIGGRAPH Asia), 2017
- Model package: FLAME2023_Open
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Project page: https://flame.is.tue.mpg.de/

The runtime asset committed in `src/assets/flame-open-lod.js` is a voxel-clustered preview LOD derived from the user-supplied FLAME2023_Open model. It is not the original full-resolution model package. The original model remains subject to its license terms and should not be redistributed except as permitted by that license.
